# DOCCAR.PRO — сайт автосервиса (Одинцово) + CRM

Лендинг автосервиса **DOCCAR.PRO** по фирменному стилю: тёмный фон `#101318`,
лаймовый акцент `#C6F34A`, доп. фон `#2A2F36`, текст `#E8ECEF`. Знак «D + пульс»,
адаптивная вёрстка, SEO-разметка и JSON-LD. Движок — тот же, что у lenkrad.ru:
Next.js + встроенная админка + лёгкая CRM на файловом сторе.

## Стек

- **Next.js 14** (App Router), **TypeScript**, **Tailwind CSS**, **lucide-react**
- Шрифты через `next/font`: Inter (текст), Montserrat (заголовки), Exo 2 (вордмарк)
- Без тяжёлых библиотек. Карта — OpenStreetMap embed в тёмной гамме (без ключей)

## Запуск

Нужен **Node.js 18.17+** (рекомендуется 20 LTS).

```bash
npm install
node scripts/gen-env.mjs   # создаст .env.local с логином/паролем админки
npm run dev                # http://localhost:3000
npm run build && npm run start
```

## Страница

| Блок | Что внутри | Редактируется |
| --- | --- | --- |
| Шапка | логотип, меню, телефон (если задан), «Записаться» | Контакты |
| Главный экран | надзаголовок, двухцветный H1, подзаголовок, фото | Главный экран |
| Услуги | карточки: фото, иконка, название, описание, стрелка → запись на эту услугу | Услуги |
| О сервисе | «По делу. Без лишних работ.» + 4 преимущества с иконками | О сервисе |
| Фото | лента фотографий (на мобильном — горизонтальная прокрутка) | Фото |
| Вопросы / контакты | заголовок, текст, кнопки, контакты, тёмная карта с маркером | Блок «Вопросы», Контакты |

Все кнопки «Записаться» открывают **окно записи** (`components/BookingDialog.tsx`,
нативный `<dialog>`): имя, телефон, услуга, авто, описание. Заявка падает в CRM
(админка → «Запросы»). Ссылка `/#booking` открывает окно сразу.

## Админка — `/admin`

Вход по логину и паролю из `.env.local` (`ADMIN_LOGIN` / `ADMIN_PASSWORD` /
`ADMIN_SECRET`). Без них действуют небезопасные значения по умолчанию
(`doccar` / `doccar-admin`) — для боевого сайта задайте свои.

**Сайт** (только владелец): контакты и **точка на карте** (координаты вставляются
одной строкой из Яндекс.Карт), тексты всех блоков, иконки, **фото во всех слотах**
(hero, карточки услуг, лента — загрузка, «Стандартное», «Убрать»), видимость
блоков, рабочие часы календаря, SEO.

**CRM**: роли «Владелец» / «Приёмщик» / «Механик», запросы с сайта, календарь
записей (день/неделя, анти-дабл-букинг), уведомления, статистика, бэкап.

## Данные

| Что | Где |
| --- | --- |
| Контент сайта | `data/content.json` (поверх дефолтов из `lib/content-model.ts`), запись атомарная |
| CRM (пользователи, заявки, записи) | `data/crm.json` |
| Загруженные фото | `data/uploads/` — отдаются через `/api/media/<id>` |
| Стартовые фото | `public/images/*.webp` |

Каталог `data/` в `.gitignore` и монтируется томом в Docker — переживает деплой.
Фото, которые больше не используются в контенте, удаляются при сохранении
(свежие загрузки младше часа не трогаются). **Бэкап** (админка → «Бэкап») —
ZIP с `content.json`, `crm.json` и всеми загруженными фото; восстановление
возвращает и фото.

Загрузка принимает JPG/PNG/WEBP/GIF до 6 МБ; тип определяется по содержимому
файла. URL картинок в контенте — только встроенные `/images/*` или `/api/media/*`.

## Структура

```text
app/
  layout.tsx, page.tsx      # метаданные, шрифты; сборка секций (force-dynamic)
  api/lead                  # приём заявки → CRM
  api/media/[id]            # отдача загруженных фото
  api/admin/*               # контент, загрузка фото, CRM, бэкап
  admin/                    # вход + панель (route-group (panel) с гардом)
components/                 # Header, Hero, Services, About, Gallery, Contacts,
                            # Footer, MobileCTA, BookingDialog, ContactForm, Logo, JsonLd
  admin/                    # редактор сайта, CRM-экраны
lib/
  content-model.ts          # типы, DEFAULT_CONTENT, хелперы (можно в клиенте)
  content.ts                # чтение/запись data/content.json (сервер)
  media.ts                  # загрузки: проверка типа, безопасные URL, уборка
  icons.tsx                 # реестр иконок (lucide + свои: монитор-пульс, ключ+отвёртка)
  crm.ts, auth.ts, zip.ts   # CRM-стор, сессии, ZIP для бэкапа
config/site.ts              # навигация, ссылки на карты из координат
public/                     # favicon.svg, icon-*.png, apple-touch-icon.png, og-image.png, images/
```

Тема: цвета — токены в `tailwind.config.ts`. Акцент — CSS-переменная: на тёмном
сайте это лайм, в светлой админке — тёмно-оливковый (`.theme-dark` / `.theme-light`
в `app/globals.css`), чтобы текст акцентом читался на белом.

## Деплой

`Dockerfile` + `docker-compose.yml` (приложение + Caddy с авто-TLS) + `Caddyfile`
под `doccar.pro` / `www.doccar.pro`. Секреты — в `.env` рядом с compose.
Порядок как у lenkrad: бэкап `data/` → выкладка исходников без `data/` и `.env`
→ `docker compose build && docker compose up -d`. Не вешать сайт на IP VPN-ноды.
